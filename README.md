## Install

https://github.com/amatak-org/AngkorCMS.git
cd AngkorCMS

pip install -r requirements.txt

## Terminal
angkor run

This will start the Angkor server on port 7000, and you can access it by navigating to 
http://localhost:7000 in your browser.
